# ユーザージャーニーと旅行計画の思考プロセス

## 実際の旅行計画プロセス

人間が旅行プランを立てる際の実際の思考プロセス。
このプロセスを理解することで、自然なAIエージェントを設計できる。

### 重要な特徴
- **段階的詳細化**: 抽象 → 具体へと段階的に決定
- **手戻りあり**: 後半で詰まったら前半に戻って調整
- **非決定的**: 順番が前後することもある

## 旅行計画の13ステップ

### 1. 目的の明確化
```
例: 「上海ディズニーに行きたい」
```

**他の選択肢**:
- a. 温泉に浸かりたい
- b. 南国リゾートに行きたい
- c. 大自然を見に行きたい

### 2. 旅先の決定
```
例: 「上海に行こう」
```

目的から旅先を決定。

### 3. 時期の決定
```
例: 「安いし寒さも気にならなそうだから、1月に行こう」
```

気候、価格、混雑状況を考慮。

### 4. 期間の決定
```
例: 「上海ディズニーに行くなら3泊4日が良さそうだ」
```

目的地と目的から適切な期間を推定。

### 5-6. 移動手段と日程の確定
```
例: 「飛行機を探そう」
     「1/17-20にしよう」
```

具体的なフライトを検索し、日程を確定。

**重要**: ここから先は予約が入るため、手順1-4に戻ることはほぼない。

---

## 大枠の決定（手順1-6）

ここまでで旅行の**フレームワーク**が確定。
- 目的
- 旅先
- 時期
- 期間
- 移動（フライト）
- 日程

**宿泊**も大枠に含まれる（フライトとホテルは抑えておきたい）。

---

### 7. 日別スケジュールの骨子
```
例: 1日目は外灘、2日目は豫園、3日目はディズニー、4日目は外灘が良さそう
```

各日の「エリア」と「テーマ」を決定。

### 8. 宿泊先の決定
```
例: 「ホテルはここにしよう」
```

日別計画を考慮して、最適な拠点エリアを選定。

---

## 詳細の充填（手順7-12）

ここからは日々の具体的な内容を詰めていく。

### 9. 観光スポットを探す
```
例: 各エリアの観光スポットをリサーチ
```

- Web検索
- レビュー確認
- 営業時間、料金確認
- 所要時間調査

### 10. 食べたいものを探す
```
例: 各エリアのレストランをリサーチ
```

- 地元おすすめ
- レビュー確認
- 価格帯
- 位置（観光スポットに近いか）

### 11. ルートを決める
```
例: 「このような順番で回ろう」
```

- 移動時間を計算
- 効率的な順序を決定
- 営業時間を考慮

### 12. スケジュールを組む
```
例: 「移動手段を含め、このようなスケジュールになりそうだ」
```

- 時刻単位でタイムラインを作成
- 移動時間を含める
- バッファを考慮

---

## 検証と調整（手順13）

### 13. スケジュールの妥当性チェック

```
スケジュールが収まりきらない、余る場合は...
→ 10, 9, 7, 6, ... と戻っていき落とし所を探る
```

**調整の優先順位**（後ろから順に）:
1. 手順12（スケジュール調整） - 滞在時間を削る
2. 手順10（食事） - レストランの変更
3. 手順9（観光） - スポットの削除
4. 手順7（日別計画） - エリア・テーマの見直し
5. 手順6（日程） - 期間の変更 ※現実的にはほぼない

**調整方法**:
- 滞在時間を削る（10-20%カット）
- 優先度の低いスポットを削除
- 食事の時間を短縮

**ユーザーへの提案**:
後ろの手順から順番に調整案を提示し、ユーザーに選択してもらう。

## レイヤー構造

```
[Layer 1] 大枠の決定（手順1-8）
  目的 → 旅先 → 時期 → 期間 → 移動 → 日程 → 日別骨子 → 宿泊
  ↓
[Layer 2] 詳細の充填（手順9-12）
  観光 → 食事 → ルート → スケジュール
  ↓
[Layer 3] 検証と最適化（手順13）
  収まらない → Layer 2 で調整 → それでも無理なら Layer 1 に戻る
  （実際にはLayer 1に戻ることはほぼない）
```

## ユーザー体験の設計指針

### 入力
- **柔軟な入力**: 最小限の情報から始められる
- **自然な会話**: フリーテキスト形式
- **段階的**: 必要に応じて追加情報を引き出す

### 生成
- **ストリーミング**: 段階的に表示（待ち時間を感じさせない）
- **透明性**: 何をしているか見える
- **スピード**: 10-30秒で完了

### 表示
- **一目でわかる**: タイムライン表示
- **俯瞰できる**: 複数日を一覧
- **深掘りできる**: 詳細情報へドリルダウン
- **楽しめる**: パンフレットのような見た目

### 編集
- **柔軟**: 全て編集可能
- **直感的**: ドラッグ&ドロップ、時間調整
- **安心**: 手動保存（意図しない変更を防ぐ）

### 共有
- **簡単**: URLコピーだけ
- **誰でも見られる**: 認証不要（MVP）
