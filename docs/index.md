## 🚀 プロジェクト概要（サマリー）

### コンセプト
「上海ディズニーに行きたい」→ 詳細な3泊4日の旅程を自動生成

### ターゲット
旅行計画を立てる時間がないが、しっかりした旅程が欲しい個人旅行者

### 技術スタック
- **フロントエンド**: TanstackStart
- **AIオーケストレーション**: Mastra
- **LLM**: GPT-5（テキスト + 画像生成）
- **バックエンド**: Cloudflare Workers
- **データベース**: Cloudflare D1（SQLite）
- **外部API**: Google Distance Matrix API, Web検索API

### MVPスコープ
- Phase 0: セットアップ（1-2日）
- Phase 1: エージェント構築（7-10日）
- Phase 2: UI実装（10-14日）
- **合計: 約1ヶ月**

## 🛠️ 開発の進め方

### 1. 環境構築
```bash
# プロジェクトセットアップ
pnpm init
pnpm add @tanstack/start mastra wrangler

# D1データベース作成
wrangler d1 create agentravel-db

# スキーマ適用
wrangler d1 execute agentravel-db --file=./docs/schema.sql
```

### 2. API接続確認
- GPT-5 API keyの取得と接続テスト
- Google Distance Matrix APIの有効化とテスト

### 3. エージェント実装
- Mastra Playgroundでサブエージェントを実装
- メインエージェントのReActループを実装
- End-to-Endテスト

### 4. UI実装
- TanstackStartでフロントエンド実装
- Cloudflare Workersでバックエンド実装
- デプロイ

## 📝 重要な設計決定

### エージェント
- **パターン**: ハイブリッド（固定フロー + ReAct）
- **対話スタイル**: 自然な会話形式
- **サブエージェント呼び出し**: 即座に実行
- **エラー対応**: 自動で代替案を提案

### データ
- **メモリ**: JSON保存（柔軟性重視）
- **保存タイミング**: 重要決定時 + 30秒ごと
- **URL**: `/users/{userid}/plans/{planid}`
- **ID**: uuidv7

### UI/UX
- **入力**: フリーテキスト（大きなエリア）
- **生成**: ストリーミング表示（10-30秒）
- **表示**: タイムライン + 俯瞰ビュー
- **編集**: フル編集可能、手動保存
- **共有**: URL共有
